# CTIA 單檔可攜版

此目錄以現有網站原始碼產生一份獨立 HTML。它不改動既有網站的功能或個人紀錄；編譯輸出不含任何使用者筆記或測驗紀錄。

```sh
python portable/build.py /absolute/output/CTIA_Practice_Portable.html
node --check /absolute/output/CTIA_Practice_Portable.check.js
npm test
```

交付時只需 HTML；`.check.js` 是語法檢查用的中間檔，不是執行依賴。所有題庫、CSS 與程式碼均內嵌，沒有外部程式套件、字型或題庫載入。只有使用者主動使用選字翻譯、參考連結等連線功能時需要網路。語音是否需網路由裝置提供的聲音決定。

## 紀錄

- 自動保存：能使用 localStorage／IndexedDB 時保存在目前瀏覽器；保存失敗則降級為記憶體暫存，頁首明確提示必須匯出。暫存模式仍可畫線與作答。
- 完整 JSON 備份：手寫筆記、作答／測驗題序與成績、原截止時間、閱讀與考試各自的已熟紀錄、閱讀語言與範圍、選字翻譯開關。
- 匯入前驗證整份資料，確認後取代本可攜版目前的筆記與上述狀態。計時測驗不因匯入而重置時間。
- 不會自動修改原 HTML；傳 HTML 給別人不會附上紀錄，換裝置請另帶 JSON。
- 本機 file URL 的儲存行為依瀏覽器而異，移動或改名檔案也可能影響自動恢復。以完整 JSON 備份作為可攜保存方式。
- 原網站現階段只有手寫備份，沒有完整紀錄匯出；其手寫 JSON 可由可攜版閱讀頁的「匯入筆記」還原。網站的作答／已熟資料不會自動帶入下載檔。

## 驗證與限制

- 單元測試包含完整備份往返、損壞檔拒絕、獨立已熟紀錄、計時與洗牌保留、儲存失敗時記憶體降級。
- HTTP 瀏覽器預覽已驗證完整匯入／匯出後 state、notes 完全一致，重整後恢復紀錄與中文錯題檢討。
- Cloud Browser 安全政策禁止 file 協定導航，未繞過限制，因此尚未以該環境驗證雙擊本機檔案。實際 Windows／macOS／手機／iPad 本機開啟需各裝置確認；不支援 JavaScript 的檔案預覽器不能當作完整瀏覽器。
- iOS 實際語音及觸控筆書寫體感尚未實機驗證，保留網站版本現有的限制。
