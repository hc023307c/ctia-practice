# CTIA 題庫練習

以提供的 88 題 Word 題庫建立的練習網站，使用原生 HTML、CSS 與 JavaScript，無需建置或 API 金鑰。

## 使用

- **閱讀版**：英文原版／繁體中文與英文逐段對照；支援題號範圍、指定題號跳轉，每題下方直接顯示答案。中英對照模式的答案下方另附中文解析，包括選答理由與觀念、其他選項比較及記憶重點。
- **考試版**：英文題目與選項；可設定範圍（例如 `1-20`、`2,5,8-15`）、抽題數、計時、題目洗牌、選項洗牌。兩個洗牌選項皆關閉即為原版。
- 可跳題、標記、清除答案與暫停離開頁面；計時測驗離開頁面仍會繼續計時。時間結束自動交卷。
- 交卷後顯示分數、正確率、作答時間、每題答案及原始題號；可篩選錯題、錯題重考或依相同設定重考。
- 同一瀏覽器保存最近一次測驗；不跨裝置同步，不需登入。清除網站資料或使用無痕模式可能遺失進度。新測驗取代上次紀錄。
- 僅供題庫練習。答案資料會傳送至瀏覽器，無法用作防作弊的正式考試系統。

## 本機啟動

```sh
python -m http.server 8000
```

開啟 `http://localhost:8000`。請透過 HTTP 服務開啟，直接雙擊 HTML 會因瀏覽器安全限制而無法載入模組及題庫。

## GitHub Pages 部署

在儲存庫 **Settings → Pages → Build and deployment** 選擇 **Deploy from a branch**，選擇 **main** 與 **/(root)**，儲存後等待部署完成。

預期網址：`https://hc023307c.github.io/ctia-practice/`。須先在設定頁啟用 Pages，僅上傳程式並不會啟用網站。

也可把本專案根目錄交給任何靜態網站主機，無建置命令與環境變數。

## 驗證

需要 Node.js 18 或以上，沒有第三方 JavaScript 依賴。

```sh
npm run check
npm test
```

驗證涵蓋題庫完整性、範圍驗證、洗牌後答案對應、不重複抽題、特殊題保留選項、複選計分、未作答統計及計時狀態持久化。

## 更新題庫

`questions.json` 是網站的唯一題庫來源。每題包含：

- `id`：原始題號，唯一且固定。
- `en`、`zh`：原始英文與繁體中文翻譯。
- `options`：具有固定 `id`（原始 A/B/C/D）、英文與中文的選項。
- `answers`：正確選項的固定 ID 陣列。洗牌只調整顯示順序，計分使用固定 ID。
- `explanation`：中文解析，含 `reason`、`distractors`、`takeaway` 與觀念參考連結 `references`；僅閱讀版中英對照模式顯示。
- `note`：閱讀與檢討時顯示的待核對提示。
- `lockOptions`：若選項含相互引用或其他不適合洗牌的內容，設為 `true`。

再次匯入 Word 可先安裝 `python-docx`，執行 `python scripts/import_docx.py source.docx`。英文或答案有變更的題目會清除中文與解析，避免舊內容誤配；補完翻譯與解析後必須重新執行檢查。

`core.js` 的 `VERSION` 是作答資料相容版本。題庫有影響答案或選項 ID 的變更時，同時更新版本，避免舊測驗狀態套用新題庫。

## 題目備註

英文與答案依提供檔案保留，中文為輔助理解的翻譯。第 4、8、12、16、54、74、77、78、85 題另有待核對提示，尚未替換原始答案。這些提示不是經官方確認的答案更正。第 78 題包含第二層小寫選項代號，因此保留原始選項順序。

88 題均有中文解析。解析是輔助理解的編寫內容，部分附官方或原作者的觀念參考，並非本題官方解答或官方審定；有疑義時區分原題答案與實務觀念。原始 Word 不放入儲存庫。

## 閱讀模式選字翻譯

只在「閱讀題庫」頁面支援。長按或反白英文題幹、英文選項中的單字、片語或句子，選取穩定約 650ms 後，底部顯示可關閉的小卡。選字時不自動移動焦點，不覆寫手機原生選字選單。

- 線上翻譯使用 MyMemory 公開 GET API，目標語言為繁體中文（`en|zh-TW`），不需 API 金鑰、個人帳號或額外後端。
- 只發送選取內容；展開「查看所在原文」後，可另外翻譯該段原文。服務回傳一般翻譯，**不宣稱具備本題語境推理或 AI 用法解析**。
- 關閉小卡、切換頁面或選取新內容時，取消舊請求並忽略過時回應。考試、成績、首頁與設定頁不觸發翻譯。
- 可關閉「選字即時翻譯」，設定保存在目前瀏覽器。
- 最近 100 筆成功翻譯保存 30 天，依文字與所在原文區分，減少重複請求；儲存不可用時仍可翻譯。
- MyMemory 單次查詢上限為 500 UTF-8 bytes，網站使用最多 450 bytes 的分段，整次選取最多 1,800 bytes。較長文字會先提示分段，不截斷內容。
- 免費匿名使用存在每日配額（提供者目前標示 5,000 字元／日），可能受共用網路出口影響；達上限會明確提示，**不把額度錯誤當作譯文**。網路失敗與逾時也有提示。
- 小卡提供另開 Google 翻譯的備援連結；只有點擊時才開啟，不會在背景自動改用另一服務。
- 介面與快取在 `reading-translation.js`，API、分段與配額錯誤處理在 `translation-service.js`。後續若需穩定較大量使用，可替換服務層為具金鑰保護的正式付費 API 後端；目前沒有啟用付費服務。

API 規格：https://mymemory.translated.net/doc/spec.php

用量規格：https://mymemory.translated.net/doc/usagelimits.php


## 每題直接畫線筆記

僅閱讀模式提供，包括英文原版與中英對照。每題左上角勾選「手寫畫線」，直接在題幹、選項、答案與解析上畫線或圈選；取消勾選後筆跡仍顯示，恢復選字翻譯與觸控捲動。沒有獨立手寫板。

- 可使用手指、裝置支援的筆或滑鼠。筆色順序為紅、藍、深綠，每題預設紅筆；舊筆跡顏色保留。工具包含三種粗細、橡皮擦、復原、重做及清空；清空前確認，且當次工作階段仍可復原。
- 畫線模式對整個題目內容（含區塊空隙）停用原生觸控捲動，搭配 Safari 非被動 touch 事件阻止手勢。落筆至抬筆期間阻止原生捲動手勢，不切換 body 的定位與寬度；抬筆、取消觸控、視窗失焦或離開閱讀頁會解除固定。一次只接受一支筆／手指；「捲動」或取消勾選後恢復正常操作。
- 「捲動」模式讓觸控操作在題目內滑動頁面；按「返回書寫」才繼續畫字。也可拖曳題卡外側捲動。書寫與原生選字使用不同輸入模式，避免畫線誤觸翻譯。
- 同一題各內容區塊分別儲存筆畫，避免中文開關造成下方筆跡整體位移。英文題幹在兩種閱讀模式共用；選項與答案依英文／中英版排版分別保存。舊手寫板筆記保留在原資料中，匯出備份時包含它們，不會錯誤覆蓋到題目上；新版清空只清除本題畫線。
- 各區塊以正規化座標儲存，依實際大小及像素密度重繪，只有鄰近視窗的區塊配置完整畫布記憶體。畫線是自由筆跡，不是文字標註：螢幕旋轉、字體或裝置寬度改變導致重新換行時，仍可能對不準原本字詞，建議固定閱讀方向與字體後書寫。
- 筆畫、橡皮擦操作與更新時間存於 **IndexedDB**，不送至後端或翻譯服務；成功完成寫入才顯示已儲存。一般在一筆完成後約 200ms 排程儲存，離開頁面或切換模式也會嘗試立即寫入。
- 最近的復原／重做歷史保留於當次展開期間；重新開啟後仍可逐筆復原已保存筆畫，但先前被清空的復原歷史不會跨重新整理保存。
- 未儲存成功時顯示錯誤，記憶體中的筆記會保留，請立即匯出備份。瀏覽器完全禁止 IndexedDB 時不開放書寫，避免誤以為內容已保存。
- 「匯出全部筆記」下載 JSON 備份，可在另一台裝置同一網站使用「匯入筆記」還原。匯入前完整驗證所有題號與筆畫，確認後以單次交易覆寫備份中包含的同題筆記；其他題目保留。
- 自動儲存不等於跨裝置同步或永久備份；清除網站資料、無痕模式與瀏覽器儲存空間政策可能使筆記遺失，請定期匯出。
- 備份格式使用 `ctia-handwriting-backup`、版本 1、題庫 `ctia-88`，最多 25MB，僅接受已知題號、工具與顏色；不載入任意圖片或 HTML。

相關程式：`reading-notes.js`（介面與筆畫操作）、`notes-store.js`（本機交易儲存）、`notes-data.js`（座標與備份驗證）。

## 已讀熟，下次略過

- 閱讀、測驗／交卷檢討的每題右上方均可勾選；以原始題號記錄，洗牌不影響對應。閱讀與考試分別存於 `ctia-mastery-read-v1`、`ctia-mastery-exam-v1`，只使用瀏覽器 localStorage，無後端。
- 閱讀進入頁面時才截取應略過的題號；新標記不會讓當前題目消失，切換語言或範圍也保留本次題目。再次進入或重新整理時略過。上方「顯示已熟題」可暫時顯示全部，取消標記後恢復閱讀。直接跳至已熟題也會開啟顯示。
- 考試只在建立新測驗時先排除已熟題，再抽題、洗牌；現有測驗的題序、作答、計時、總題數與成績完全保留。相同設定重考及錯題重考也依最新考試已熟標記篩選；勾選「包含已熟題出題」則可整批複習。
- 設定頁有「查看與恢復考試已熟題」清單，可逐題取消。範圍提示顯示可用題數；全部已熟時提供恢復提示，不建立空測驗。指定題數超過剩餘可出題數時，顯示數量錯誤讓使用者調整。
- 儲存失敗時回復勾選狀態並明確提示，不顯示成功。跨分頁同步勾選與統計，不中斷目前畫線或刪掉本次題目。
- 只略過顯示／出題，不刪除題庫、答案、解析或手寫筆跡。資料僅在目前裝置／瀏覽器，清除網站資料會清除標記；手寫筆記備份不包含此獨立的已熟紀錄。

### Safari 異常連線修正

- 不再於每次落筆／抬筆切換 body 固定定位或呼叫 scrollTo，避免改變書寫中的座標系。整個題卡的 touch-action 限制與非被動手勢阻止仍保留。
- 一筆使用同一份畫布位置；位置或尺寸改變、點超出畫布、單次跳動超過 96 CSS px 時結束該筆，不把異常點連到舊筆跡，也不把超界座標壓到邊緣。很快、取樣間距過大的長筆畫可能被截斷，需要抬筆重畫。
- 僅使用當下 PointerEvent，不再串接 coalesced 事件；忽略較舊時間與其他指標的點。非主要觸點不開始書寫；抬筆／取消、失焦與視覺視窗變更均會結束當筆。這不是完整的硬體手掌辨識。
- 既有筆記不自動修改；舊異常線可用橡皮擦、復原或本題清空處理。
